# Forward SMS & Calls to Telegram

Сервис для автоматического пересылки входящих SMS-сообщений и уведомлений о входящих звонках с USB/GSM-модема прямо в Telegram. 

Приложение работает через serial-порт (AT-команды), что позволяет использовать большинство популярных USB-модемов (Huawei, ZTE, Quectel и др.) для создания систем уведомлений, SMS-шлюзов или интеграции с системами умного дома.

## 🚀 Возможности
* 📩 Пересылка текста входящих SMS-сообщений.
* 📞 Уведомления о входящих звонках (отправка номера телефона).
* 🐳 Готовность к запуску в Docker.
* ⚙️ Гибкая настройка через переменные окружения.

---

## ⚠️ Подготовка хост-системы (Важно для некоторых модемов)

Многие современные 3G/4G USB-модемы при подключении к компьютеру определяются как виртуальный CD-ROM с драйверами, а не как модем. Чтобы перевести устройство в режим модема и открыть нужные serial-порты (например, `/dev/ttyUSB0`, `/dev/ttyUSB2`), на хост-машине должны быть установлены специальные утилиты.

Если ваш модем не определяется корректно, выполните на хост-машине:

```bash
sudo apt update
sudo apt install usb-modeswitch usb-modeswitch-data
```

*После установки утилит отключите и снова подключите USB-модем. Проверьте появление портов командой `ls /dev/ttyUSB*`.*

## ⚙️ Переменные окружения

| Переменная | Описание | Пример |
| :--- | :--- | :--- |
| `SERIAL_PORT` | Путь к serial-порту модема внутри контейнера. Обычно это порт, отвечающий за AT-команды (часто `ttyUSB2` или `ttyUSB0`). | `/dev/ttyUSB2` |
| `TG_TOKEN` | Токен вашего Telegram-бота (получается у [@BotFather](https://t.me/BotFather)). | `785432109:AAE1a2B3c4D5e6F7g8H9i0J1k2L3m4N5o6P` |
| `TG_CHAT_ID` | ID чата, группы или пользователя, куда будут отправляться SMS и звонки. | `123456789` |
| `LOG_LEVEL` | Уровень детализации логов. Доступны: `DEBUG`, `INFO`, `WARNING`, `ERROR`. | `DEBUG` |

## 🐳 Запуск через Docker Compose

Создайте файл `docker-compose.yml` и добавьте в него следующую конфигурацию:

```yaml
services:
  forward-sms-calls-to-telegram:
    image: metro2012/forward-sms-calls-to-telegram:latest
    pull_policy: always
    container_name: forward-sms-calls-to-telegram
    restart: unless-stopped
    devices:
      - "/dev/ttyUSB2:/dev/ttyUSB2"
    environment:
      - SERIAL_PORT=/dev/ttyUSB2
      - TG_TOKEN=785432109:AAE1a2B3c4D5e6F7g8H9i0J1k2L3m4N5o6P
      - TG_CHAT_ID=123456789
      - LOG_LEVEL=DEBUG
```

### Запуск:
```bash
# Запуск в фоновом режиме
docker compose up -d

# Просмотр логов
docker compose logs -f forward-sms-calls-to-telegram
```

## 📱 Как получить TG_TOKEN и TG_CHAT_ID?

1. **Токен бота (`TG_TOKEN`):**
   * Найдите в Telegram бота [@BotFather](https://t.me/BotFather).
   * Отправьте команду `/newbot` и следуйте инструкциям.
   * Скопируйте полученный токен (формата `123456789:ABCdefGHI...`).

2. **ID чата (`TG_CHAT_ID`):**
   * Найдите в Telegram бота [@userinfobot](https://t.me/userinfobot) или [@getmyid_bot](https://t.me/getmyid_bot).
   * Напишите ему любое сообщение, и он ответит вашим личным ID.
   * *Если нужно отправлять сообщения в группу:* добавьте бота в группу, напишите в группу сообщение, и бот пришлет ID этой группы (обычно начинается с минуса, например `-1001234567890`).

## 🛠️ Troubleshooting (Решение проблем)

1. **Контейнер падает с ошибкой `Permission denied` или `device not found`:**
   * Убедитесь, что модем подключен и порт существует (`ls /dev/ttyUSB*`).
   * Проверьте, что у пользователя `root` (или того, от кого запускается Docker) есть права на чтение/запись устройства. В крайнем случае можно добавить `privileged: true` в `docker-compose.yml`, но маппинг конкретного устройства (`devices`) безопаснее.

2. **Модем отвечает ошибкой на AT-команды:**
   * У разных модемов AT-команды могут находиться на разных портах. Если `ttyUSB2` не отвечает, попробуйте изменить `SERIAL_PORT` на `/dev/ttyUSB0` или `/dev/ttyUSB1` (не забудьте обновить маппинг `devices` в compose-файле).
   * Порт для AT-команд обычно определяется через `dmesg | grep ttyUSB` (ищите порт, который определяется как "Modem" или "AT Port").

3. **SMS не приходят, хотя модем в сети:**
   * Убедитесь, что SIM-карта активна, имеет баланс и на ней нет переполненной памяти SMS (в некоторых модемах нужно вручную очищать хранилище).
   * Включите `LOG_LEVEL=DEBUG` и посмотрите вывод `docker compose logs`, чтобы увидеть сырой ответ модема на AT-команды.
