# Forward SMS & Calls to Telegram

Сервис для интеграции USB/GSM-модема с Telegram. Бот не только автоматически пересылает входящие SMS и уведомляет о звонках, но и позволяет **отправлять SMS, совершать звонки-сбросы** (дозвон) и **отправлять USSD-запросы** (проверка баланса и др.) прямо через команды в Telegram.

Приложение работает через serial-порт (AT-команды), что позволяет использовать большинство популярных USB-модемов (Huawei, ZTE, Quectel и др.) для создания систем уведомлений, SMS-шлюзов или интеграции с умным домом.

## 🚀 Возможности
* 📩 **Входящие SMS:** Автоматическая пересылка текста входящих SMS в Telegram (с поддержкой склейки длинных сообщений и кириллицы).
* 📥 **Пропущенные SMS:** Чтение непрочитанных сообщений из памяти модема при старте контейнера.
* 📞 **Входящие звонки:** Уведомления о входящих звонках (отправка номера телефона) и автоматический сброс вызова через заданное время.
* ✉️ **Отправка SMS:** Отправка сообщений на любой номер прямо из чата с ботом.
* ☎️ **Исходящие звонки:** Команда для выполнения звонка-сброса (бот звонит на указанный номер и кладет трубку через заданное время).
* 💰 **USSD-запросы:** Выполнение USSD-команд прямо из чата (например, проверка баланса).
* 🐳 Готовность к запуску в Docker и гибкая настройка через переменные окружения.

## 💬 Команды Telegram-бота

Отправьте эти команды вашему боту в Telegram:

* `/help` или `/start` — Показать справку по доступным командам.
* `/call <номер>` — Совершить исходящий звонок-сброс. (Пример: `/call +79991234567`)
* `/sms <номер> <текст>` — Отправить SMS. (Пример: `/sms +79991234567 Привет, это проверка связи!`)
* `/ussd <код>` — Отправить USSD-запрос. (Пример: `/ussd *100#` или `/ussd *102#`)

## ⚙️ Переменные окружения

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `TG_TOKEN` | *(обязательно)* | Токен вашего Telegram-бота (получается у [@BotFather](https://t.me/BotFather)). |
| `TG_CHAT_ID` | *(обязательно)* | ID чата, группы или пользователя для получения уведомлений. |
| `SERIAL_PORT` | `/dev/ttyUSB2` | Путь к serial-порту модема внутри контейнера (AT-порт). |
| `BAUD_RATE` | `115200` | Скорость подключения к порту модема. |
| `OUTGOING_CALL_DURATION` | `5.0` | Продолжительность исходящего звонка в секундах до авто-сброса (`/call`). |
| `INCOMING_CALL_DURATION` | `2.0` | Задержка в секундах перед тем, как бот сбросит входящий вызов. |
| `CLIP_DEBOUNCE_TIME` | `10.0` | Антиспам-фильтр (в сек.) для входящих звонков с одного и того же номера. |
| `LOG_LEVEL` | `INFO` | Уровень детализации логов (`DEBUG`, `INFO`, `WARNING`, `ERROR`). Установите `DEBUG` для просмотра AT-команд. |

## 🐳 Запуск через Docker Compose

Создайте файл `docker-compose.yml` и добавьте в него следующую конфигурацию:

```yaml
services:
  forward-sms-calls-to-telegram:
    image: metro2012/forward-sms-calls-to-telegram:latest
    pull_policy: always
    container_name: forward-sms-calls-to-telegram
    restart: unless-stopped
    devices:
      - "/dev/ttyUSB2:/dev/ttyUSB2"
    environment:
      - SERIAL_PORT=/dev/ttyUSB2
      - BAUD_RATE=115200
      - TG_TOKEN=785432109:AAE1a2B3c4D5e6F7g8H9i0J1k2L3m4N5o6P
      - TG_CHAT_ID=123456789
      - LOG_LEVEL=INFO
      - OUTGOING_CALL_DURATION=5.0
      - INCOMING_CALL_DURATION=2.0
      - CLIP_DEBOUNCE_TIME=10.0
```
